The Cast of Characters

Every app is built from pieces that each do one job well. Think of them as actors in a play — each has a role, a script, and a place on stage. Here are the five main characters in our app.

⚙
DebateEngine

The referee. Lives in debate_engine.py. Runs the debate loop, tracks state, and manages whose turn it is. Like a debate moderator who also runs the scoreboard.

★
Agents

The debaters' brains. Each agent in agents.py knows its stance, personality, and has tools like web search. Like giving each debater a brain transplant with a different personality each time.

🔍
Web Search Tool

The research assistant. tools.py searches Brave Search and returns results. Has a built-in rate limiter (max 1 search per second) so it stays polite.

🔗
FastAPI Server

The switchboard operator. main.py routes incoming requests to the right endpoint, serves the frontend, and manages SSE connections.

🎬
Frontend

The stage. app.js + index.html render the debate in real-time using SSE events. Handles debater selection, drag-to-reorder, and renders markdown into styled text.

💡
Key Insight

Every piece of software has a "separation of concerns" pattern — each file handles one job. main.py handles HTTP requests, debate_engine.py handles debate logic, agents.py handles AI personalities, and tools.py handles external searches. When you need to change something, this separation tells you exactly where to look. This pattern is the #1 thing that helps you steer AI coding tools effectively — you can say "put this logic in the engine, not the API layer" and get better code.

Notice the chain: FastAPI receives the request, DebateEngine orchestrates, Agents think (sometimes calling the Search Tool), and the Frontend renders. Each component only talks to its immediate neighbors — they never skip links in the chain.

The Architecture

Here is how all five components fit together. The app is split into three zones: your Browser, the Server, and the External World. Click any component to learn what it does.

Browser Zone
🎬 Frontend index.html + app.js + style.css
Server Zone
🔗 FastAPI Server main.py
⚙ DebateEngine debate_engine.py
★ Agents agents.py
External Zone
🤖 LLM API DeepSeek / OpenAI / Ollama
🔍 Brave Search search API
Click any component above to see what it does.

The arrows go one way: Browser sends requests to the Server, and the Server streams responses back. The Server calls out to external APIs for AI brains and web search. The module structure keeps each concern isolated.
